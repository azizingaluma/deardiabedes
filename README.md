# Dear Diabetes
1. `npm install && npm run dev`
2. Letters: edit `content/letters.ts`. The current text is DRAFT copy; paste your exact letters there.
3. Audio: add a licensed or royalty-free `public/piano.mp3` (no autoplay).
4. Deploy: push to GitHub, import the repo at vercel.com/new, keep defaults, Deploy.
5. Drafts are saved in localStorage only. Publishing and moderation need a backend (e.g. Supabase) you add later. Story cards are fictional samples.
